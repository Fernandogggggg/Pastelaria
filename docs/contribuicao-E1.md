# Contribuição — E1

Os commits devem ser realizados individualmente por cada elemento do grupo, com a conta GitHub correta e uma mensagem clara.

| Elemento | Meta mínima | Registo a preencher |
|---|---:|---|
| Fernando | 3 commits | `1. ___` · `2. ___` · `3. ___` |
| Jose | 3 commits | `1. ___` · `2. ___` · `3. ___` |
| Gonçalo | 3 commits | `1. ___` · `2. ___` · `3. ___` |

Sugestão de divisão: estrutura HTML, conteúdo e imagens, CSS/documentação/validação. Cada pessoa deve rever as alterações antes de fazer o seu commit. Não foram feitos commits automaticamente nesta preparação.
