Guia de Estilo — Pastelaria

Este documento define as cores e a tipografia utilizadas no site da pastelaria, garantindo uma aparência visual consistente e agradável.


Palete de cores

Nome:                  Código hexadecimal:            Utilização: 
Castanho               #6F4E37                      Títulos e elementos principais
Bege                   #F5E6CC                      Fundos de secções
Laranja                #E89B3C                      Botões e elementos de destaque
Branco                 #FFFFFF                      Fundo principal
Cinzento-escuro        #333333                      Texto normal


Tipografia

Títulos:
Tipo de letra: Georgia
Tamanho do título principal: 32 px
Tamanho dos subtítulos: 24 px
Peso: Negrito

Texto normal:
Tipo de letra: Arial
Tamanho: 16 px
Peso: Normal



Regras de utilização

O castanho deve ser utilizado nos títulos e nos elementos principais.
O bege pode ser utilizado como fundo de secções.
O laranja deve destacar botões e elementos importantes.
O branco deve proporcionar um fundo limpo e simples.
O cinzento-escuro deve ser utilizado no texto normal para facilitar a leitura.
Os títulos devem utilizar Georgia.
O texto normal deve utilizar Arial.
A tipografia deve manter-se consistente em todas as páginas do site.
